# 开源软件开发与技术 · 课程大纲

## 一、课程概况

| 项目     | 安排                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 总学时   | 32学时：理论24学时，上机8学时                                                          |

| 上机安排 | 学生自主完成平时作业和个人课程项目，教师答疑；不安排独立教学内容                       |
| 考核方式 | 平时表现10% + 平时作业50% + 个人课程项目40%；无期末考试                                |
| 课程仓库 | [`OSSDT-26`](https://github.com/USTB-SE-Course/OSSDT-26)，存放课件、发布作业和提交作业 |

课程以Python开源软件开发为主线，贯通版本管理、依赖管理、Coding Agent辅助开发、测试、持续集成、软件发布与社区协作。重视过程规范和可复现性，不以功能复杂度为主要目标。

## 二、学习目标

完成课程后，学生应能够：

1. 解释开源软件的基本概念、协作方式与许可证的作用。
2. 使用Git和GitHub管理版本，通过Issue、Pull Request（PR）和Code Review参与协作。
3. 使用uv管理Python项目与依赖，结合Coding Agent开发功能，并独立核查生成结果。
4. 使用pytest、Ruff、pre-commit和GitHub Actions建立测试与质量检查流程，使用Docker构建运行环境。
5. 完成Python软件打包、版本发布和开源文档。
6. 识别基本的软件供应链、许可证与凭据泄露风险。

## 六、个人课程项目（共40分）

### 6.1 项目任务

每位学生在**新建的独立GitHub仓库**中，从零开发一个简单但完整的Python开源软件，例如命令行工具、文件处理工具或数据转换工具。不要求复杂功能，重点是功能可用、过程可追溯、环境可复现和发布规范。

项目应包含：

- **可运行功能**：完成明确的小需求，提供示例、安装与运行方法。
- **Git与依赖管理**：保留有意义的迭代提交，使用uv、`pyproject.toml`和 `uv.lock` 管理项目及依赖，不提交虚拟环境。
- **测试与质量检查**：使用pytest覆盖核心行为及必要的边界、异常情况；配置Ruff和pre-commit。
- **持续集成**：使用GitHub Actions自动运行测试与质量检查；从干净环境按锁文件安装依赖，验证可复现性。uv配置可参考[官方CI指南](https://docs.astral.sh/uv/guides/integration/github/)。
- **开源文档与许可证**：提供README、合适的LICENSE、贡献说明，并核查依赖及引用素材的许可要求。
- **版本发布**：创建版本Tag及对应的GitHub Release，说明版本变化与使用方式。GitHub Release为必需项；Docker容器化和正式PyPI发布为可选项，不作为取得满分的前提。
-  **工具使用说明**：如使用Coding Agent，在README中简要说明其用途及人工核查方式。

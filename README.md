# 开源软件开发与技术 · OSSDT-26

本仓库用于发布《开源软件开发与技术》课程的课程大纲、课件和作业要求，并接收平时作业提交材料。课程以Python开源软件开发为主线，涵盖版本管理、依赖管理、Coding Agent辅助开发、测试、持续集成、软件发布与社区协作。

课程共32学时（理论24学时、上机8学时）。考核由平时表现（10%）、平时作业（50%）和个人课程项目（40%）组成，无期末考试。

## 仓库结构

```text
OSSDT-26/
├── README.md          # 课程入口与仓库导航
├── Syllabus.md        # 课程大纲
├── slides/            # 课程课件
└── assignment[1-7]/   # 7次平时作业
    └── README.md      # 作业要求与提交方式
```

## 使用导航

- **课程大纲**：[Syllabus.md](./Syllabus.md)说明教学安排、考核方式、个人课程项目要求及评分标准。
- **课程课件**：[slides/](./slides/)存放各讲课件。
- **平时作业**：各作业目录下的 `README.md` 给出具体作业要求与提交方式；学生按要求向对应目录提交材料。

作业代码保存在学生自行创建的练习仓库中，本仓库接收相应Markdown材料或提交索引。个人课程项目另建独立仓库，具体要求见课程大纲。

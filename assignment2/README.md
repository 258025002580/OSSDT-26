# Assignment2：Git分支、PR协作与合并冲突处理

**分值：8分｜完成方式：个人完成，同学辅助协作｜截止时间：12月2日下午18:00**

## 一、作业目标

- 独立创建GitHub仓库，完成本地与远程仓库之间的基本操作。
- 使用分支和Commit管理修改，通过Pull Request（PR）合并变更。
- 与同学协作，实际产生并解决一次合并冲突（Merge Conflict）。
- 记录实际使用的Git命令，提供可核查的操作证据。

## 二、作业要求

### 1. 创建个人练习仓库

在自己的GitHub账号下新建仓库，例如 `git-practice`，并将其克隆到本地。仓库中至少包含：

- `README.md`：简要说明仓库用途。
- 一个用于修改和冲突练习的文本文件，例如 `practice.md`。

本次作业以Git操作为主，不要求编写程序。练习仓库与教师课程仓库分开，也不作为个人课程项目仓库。

### 2. 完成分支与提交练习

在个人练习仓库中：

1. 从默认分支创建一个功能分支，例如 `feature/intro`。
2. 在该分支修改文件，完成至少两次有实际内容的Commit，提交说明应能概括修改目的。
3. 将分支推送至GitHub，向自己仓库的默认分支发起PR，说明修改内容。
4. 检查差异并合并PR，随后将本地默认分支同步到最新状态。

记录创建和切换分支、查看状态与差异、暂存、提交、推送及同步等实际使用的命令。不要为了凑提交数量制造无意义修改。

### 3. 邀请同学完成协作

邀请至少一名同学辅助完成，可以是本课程同学，也可以是课外同学。建议采用Fork方式：

- 同学Fork你的练习仓库，在自己的分支修改练习文件，向你的仓库发起PR。
- 你作为仓库所有者检查变更，并参与后续的冲突处理与合并。

也可邀请同学作为仓库协作者，在同一仓库的不同分支开展练习。协作应使用各自的GitHub账号，无须共享账号或密码。

每名学生都须在**自己的练习仓库**完成上述要求，不能仅凭帮助他人完成操作代替自己的作业。同一对同学可以互相辅助。

### 4. 实际产生并解决一次合并冲突

必须亲自处理一次真实的合并冲突。建议使用以下流程，其中“默认分支”以你的仓库实际设置为准：

1. 在 `practice.md` 中写入一行文字并提交，确保你与同学的练习分支都基于这一版本。
2. 同学在协作分支上将该行改为版本A，提交并向你的默认分支发起PR，暂不合并。
3. 你在默认分支上将同一行改为不同的版本B，提交并推送。此时协作分支和默认分支对同一位置有不同修改。
4. 在本地获取同学的协作分支并切换到该分支，获取最新默认分支，再将默认分支合并到该协作分支，触发冲突。
5. 查看冲突提示和文件中的冲突标记，判断应保留或组合哪些内容；编辑文件，移除冲突标记，暂存并提交解决结果。
6. 将解决冲突后的提交推送到发起PR的分支，使原PR更新；随后合并该PR，并检查默认分支中的文件是否包含预期内容。

如果你无权推送同学Fork中的分支，可以将本地解决后的分支推送到自己的仓库，并从该分支创建一个替代PR；合并替代PR后，在原PR中注明替代PR链接并关闭原PR。保留同学的原始提交记录和协作证据。

也可采用其他能真实产生冲突的流程。**冲突必须由Git合并操作产生，不能手动写入冲突标记作为替代。**冲突解决应由你亲自完成，并说明选择最终内容的理由。
